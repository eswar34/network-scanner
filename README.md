# ⚡ CyberHack Pro - Advanced Network Penetration Tool

A stunning hacker-themed network security scanner with a terminal interface, built with modern web technologies. This tool provides comprehensive network analysis capabilities through an immersive cyberpunk user experience.

## 🎯 Features

### 🔥 Core Functionality
- **Real-time Network Scanning** - Ping and port scanning capabilities
- **Terminal Interface** - Authentic hacker-style command line experience
- **Matrix Background** - Animated cyberpunk visual effects
- **Fallback Mode** - Works even without nmap installed
- **Export Results** - Download scan reports as HTML files

### 🎨 Visual Design
- **Hacker Theme** - Dark terminal aesthetic with green matrix effects
- **Animated Elements** - Glowing effects, matrix rain, and smooth transitions
- **Responsive Design** - Perfect on desktop, tablet, and mobile
- **Terminal Windows** - Authentic command line interface styling
- **Dynamic Sections** - Clearly divided interface sections

### ⚡ Technical Features
- **Modern Stack** - Node.js, Express, Webpack, Vanilla JavaScript
- **Real-time Validation** - Input validation with visual feedback
- **Progress Indicators** - Animated scanning progress
- **Toast Notifications** - Cyber-themed popup messages
- **Keyboard Shortcuts** - Enhanced user experience

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- nmap (optional, for advanced scanning)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/cyberhack-pro.git
   cd cyberhack-pro
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Build the application**
   ```bash
   npm run build
   ```

4. **Start the server**
   ```bash
   npm start
   ```

5. **Open your browser**
   Navigate to `http://localhost:3000`

## 🎮 Usage

### Web Interface
1. Open the application in your browser
2. Enter a target IP address or hostname
3. Click "INITIATE SCAN" or press Enter
4. View real-time scan results
5. Export results if needed

### Command Line
- **Windows**: Run `network_scanner.bat`
- **Linux/Mac**: Run `./network_scanner.sh`

### Quick Targets
- Google DNS (8.8.8.8)
- Google (google.com)
- GitHub (github.com)
- Router (192.168.1.1)

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Build Tool**: Webpack
- **Styling**: Custom CSS with animations
- **Fonts**: JetBrains Mono, Orbitron, Space Mono
- **Icons**: Font Awesome
